## 4. Geography

The five were geocoded by Nominatim to the house itself (house number matched), and distances were
computed from one fresh Overpass pull against overpass-api.de, run in the desktop browser because the
cloud workspace cannot reach either OSM host. The code measures in haversine metres (R = 6371 km),
as every earlier pull did; a first version with a flat-earth scale was 0.5% short and was not used.
Control: 1236 Thorpe and 2250 Munn's reproduced exactly on every column, 2161 Devlin and
659 Cherrywood within 9 m. Each new `geo.json` entry says so in its `_note`.
