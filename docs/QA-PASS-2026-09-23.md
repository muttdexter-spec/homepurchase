## 3. How the facts were obtained

- **MLS fields** read from the collapsed DOM (`textContent` of `dl.property-details` and the
  room rows). No accordion header was clicked. "Read More" was the only click.
- **Photos**: every listing's full Size 3 set (1024 px) through `window.__P` after the
  "View All" button or the hero click on TRREB. One contact sheet, one locate, one or two reads
  per listing. 736 photos across the 18.
- **Schools**: nearest school and count within 1 km from each listing page's own school list.
  The first extraction regex missed the list on 16 of 18 pages; each page was re-opened and read
  a second time. No school distance is estimated.
- **Geocoding**: Nominatim resolved all 18 to the house itself (exact house number), not a
  street centroid.
- **Distances**: one fresh Overpass pull against `overpass-api.de`, same feature definitions as
  `geo.json _meta.features`. **The cloud workspace's egress now blocks both OSM hosts**, so the
  pull ran in the desktop browser. Control: the same code recomputed Devlin, Hazelwood and
  Cherrywood within 5 m on every column, and 2501 Yarmouth within 35 m.

## 4. What a reviewer should push back on

**4.1 Seven build years are not facts.** Shepherd's (1955), Morgan (1970), Terraview (1972),
Mountain Grove 2037 (1968), Sycamore (1970) and Parker (1962) are neighbourhood estimates with
the source written in `year_built_est_src`. Arnold and Munn's carry only the TRREB band 31 to 50
and resolve to 1976 by the existing older-end rule. Every one carries the "Build year estimated"
stamp. Parker's band is 51 to 99, which the older-end rule would read as 1927; it was estimated
at 1962 instead, the same treatment Maplewood got.

**4.2 Photos cannot promote, and this batch is mostly renovated.** Shepherd's, Arnold, Munn's,
Sycamore, Parker, Barker and Thorpe all read new in the photographs. Every one of those reads is
`unverified`. Three of them are flips or mid-renovation, and the real question on each is
permits, which the model has no field for:
- **1041 Shepherd's**: sold as a permitted flip. No year built, painted exterior brick, painted
  walk-up block, drywalled basement, panel behind a cover.
- **2358 Arnold**: turned into a two-kitchen, 3+4 bedroom house. Registered second unit or not
  is the first question.
- **1237 Sycamore**: renovation unfinished per the remarks ("final finishing touches
  remaining"), and **8 of 39 frames are virtually staged** (31 to 38).

**4.3 2250 Munn's is a link home, not a detached.** Every other house in the model is detached.
The model has no attached flag, so it is scored as if detached and the card notes it.

**4.4 755 Parker's primary bedroom is in the basement.** The three above-grade bedrooms are 90,
134 and 169 sq ft. `ensuite` is recorded True because the basement primary has one.

**4.5 Six new pools.** Sycamore, Parker, Nevarc, Barker, Yarmouth 2452 and Meadow Lane carry
HOLD: POOL. As with Devlin, the annual carry is priced and **no pool capital
item is**, because there is no catalog line for one. Parker also has a hot tub, which nothing prices.

**4.6 Green part on two Appleby houses.** Idlewood and Meadow Lane take their green part from
"Centennial Trail", a 7.4 ha OSM `leisure=park` polygon that is really a linear trail corridor.
The 5 ha rule counts it as written. A person would score it lower.

**4.7 Short keys collided, and the fix is the one code change in this pass.** The card key is
the street part of the slug, so 2037 Mountain Grove collided with 1453 Mountain Grove, and 2452
Yarmouth with 2501 Yarmouth. That key is also the DOM id suffix and the key tiers, the view list
and gut scores are stored under on the phone. `short()` in `build_walkthrough.py` (and the copy
in `inject_showing.py`) now appends the house number only when a street repeats, and only to the
later listing. **All 40 existing keys are byte-identical**, so nothing already stored on a phone
moves. New keys: `mountain-grove-2037`, `yarmouth-2452`.

**4.8 One new stamp.** "Conditionally sold" for `status: conditional`, same class as the
existing "Back on market". Aldridge is the only card that carries it.
