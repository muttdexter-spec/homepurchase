# deliverables

`pipeline/refresh.sh` writes `renovation-cost-detail.md` here: every listing, every renovation
line, with its probability and its cost. Nothing else lands here any more. The two page builds
go straight to the repo root as `full.html` and `mobile.html`, so publishing is just a commit.

Only this README is kept in the repo. A copy of the renovation detail as of the last run is in
`docs/renovation-cost-detail.md`.
